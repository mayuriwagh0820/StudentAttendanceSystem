# Student Attendance Management System

## Project Overview
The Student Attendance Management System is a simple web application that helps teachers record and view student attendance.

## Features
- Add students using their name and roll number.
- Mark students as present or absent.
- Save and view attendance records.
- Prevent duplicate student roll numbers.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open the application in a web browser.

## Current Limitation
Attendance records are stored temporarily in browser memory and are cleared when the page is refreshed.

## Purpose
This project demonstrates basic attendance management and Git-based version control.
